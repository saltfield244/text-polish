# 用語辞書
#
# 音声入力(Win+H)で誤変換されやすい表記と、正しい表記の対応を登録します。
# 整形時に毎回LLMへ渡され、左側の表記を右側に直させます。
#
# 書き方:
#   誤変換されがちな表記 → 正しい表記
#
# ・1行に1組です。矢印は「→」でも「->」でも構いません。
# ・'#' で始まる行と空行は無視されます。
# ・このファイルがなくても動作します(辞書なしとして扱われます)。
# ・編集後はアプリの再起動なしで、次回の整形から反映されます。
#
# 登録の目安:
#   Win+H は文の構造は正確ですが、社名・製品名・人名といった固有名詞で崩れます。
#   実際に誤変換された表記をそのまま左側に書くのが最も効果的です。
#
# 例(不要なら削除してください):
番号ファン → 晩ご飯
