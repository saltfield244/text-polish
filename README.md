# TextPolish

選択したテキストを、LLMで整形してその場に置き換える Windows 常駐ツールです。

音声入力そのものは Windows 標準の音声入力（Win+H）に任せ、本ツールは
**その出力を整えること**に専念します。Win+H は速くて精度も高い一方、
フィラー（「えーと」など）や同音異義語の誤変換が残ります。そこを直すのが目的です。
手で打った文章の整形にも使えます。

```
文章を入力（Win+H でも手打ちでも）
   ↓
整形したい範囲を選択 → ホットキー（既定 F10）
   ↓
パレットで整形方法を選ぶ
   ↓
LLMで整形 → 結果を確認・編集
   ↓
選択範囲を整形結果で置き換え
```

## できること

- **プリセットによる整形** — 整える / 誤変換だけ直す / ビジネスメール / チャット / 要約 / 英訳 / 和訳
- **プリセットの組み合わせ** — 「要約 → 英訳」のように順に適用。矛盾する組み合わせは選べないようになっています
- **自由指示** — 「もっと短く」など、その場で書いた指示を適用。履歴から再利用できます
- **差分ハイライト** — 何が変わったかを色分け表示。書き換えが大きい場合は自動的に抑制されます
- **用語辞書** — 誤変換されやすい表記と正しい表記の対応を登録し、毎回の整形に反映します
- **即実行** — パレットを出さず、既定プリセットで整形してそのまま置き換えるホットキー
- **カーソル周辺の文脈の利用** — 固有名詞の誤変換を文脈から判断させます

## 対応するLLM

`appsettings.json` または設定画面から切り替えます。

- OpenAI互換の Chat Completions API（OpenRouter、OpenAI、ローカルサーバー等）
- Azure OpenAI
- Gemini

GPT-5 系のような推論モデル向けに `reasoning_effort` / `verbosity` /
`max_completion_tokens` を任意で指定できます（未指定なら送信しません）。

## 動作要件

- Windows
- .NET 10 Desktop Runtime (x64) — ビルドするなら .NET 10 SDK
- LLM の APIキー

外部NuGetパッケージには依存していません。

## インストール

[Releases](../../releases) から `TextPolish-v*-win-x64.zip` をダウンロードし、
任意のフォルダに展開して `TextPolish.exe` を実行するとタスクトレイに常駐します。
初期設定はトレイアイコンの右クリック →「設定」から行います。

ダウンロードしたZIPには「他のコンピューターから取得したファイル」の印が付くため、
展開前にプロパティから「許可する」にチェックを入れてください。
署名なしの実行ファイルのため、初回起動時に SmartScreen の警告が出ます。
手順の詳細は [README-インストール手順.txt](README-インストール手順.txt) にあります。

## ソースからビルドする

```
dotnet publish src\TextPolish.App\TextPolish.App.csproj -c Release -r win-x64 --self-contained false -o publish
```

## 注意

APIキーは `appsettings.json` に平文で保存されます。取り扱いにご注意ください。

整形のために、選択したテキスト・アクティブなアプリ名・カーソル周辺のテキスト・
用語辞書の内容が、設定したLLMのAPIへ送信されます。詳細は
[README-インストール手順.txt](README-インストール手順.txt) の
「送信されるデータについて」を参照してください。
