================================================================
 TextPolish - テキスト整形ツール - インストール手順
================================================================

■ このツールについて

選択したテキストを、LLMで整形して置き換える常駐ツールです。

音声入力そのものは Windows 標準の音声入力(Win+H)に任せ、
本ツールは「その出力を整える」ことに専念します。
Win+H は速くて精度も高い一方、フィラー(「えーと」など)や
同音異義語の誤変換が残ります。そこを自動で直すのが目的です。

もちろん、手で打った文章の整形にも使えます。


■ 前提条件(必須)

このアプリの動作には .NET 10 Desktop Runtime (x64) が必要です。
未インストールの場合、起動時にエラーが出ます。

  https://dotnet.microsoft.com/download/dotnet/10.0

  ダウンロードページの
  「.NET Desktop Runtime 10.x.x」→「Windows x64 Installer」
  を選んでインストールしてください。

整形にはLLMのAPIを使うため、インターネット接続とAPIキーが必要です。


■ インストール

1. 配布された TextPolish-v*-win-x64.zip をダウンロードします。

2. ZIPを右クリック →「プロパティ」を開き、下部に「セキュリティ:
   このファイルは他のコンピューターから取得したものです」と出ていたら
   「許可する」にチェックを入れて OK を押します。
   ※ インターネット経由で入手したファイルに付く印です。
      展開前に外しておかないと、実行時にブロックされることがあります。

3. ZIPを右クリック →「すべて展開」で、任意の場所に展開します。
   例: C:\Tools\TextPolish\
   ※ Program Files 配下は書き込み権限の関係で避けることを推奨します。
      設定ファイルを同じフォルダに書き込むためです。

4. 展開してできた TextPolish.exe をダブルクリックで起動します。
   「WindowsによってPCが保護されました」と表示された場合は
   「詳細情報」→「実行」を選んでください。
   ※ 署名なしの実行ファイルのため表示されます。

5. タスクトレイに常駐します(アイコンが出ます)。

■ 初回設定

トレイアイコンを右クリック →「設定」を開きます。

--- 「LLM」タブ ---

整形に使うLLMを設定します。
プロバイダを選ぶと、そのプロバイダ用の入力欄だけが表示されます。

  ・OpenAI互換(OpenRouter等)
      エンドポイント: https://openrouter.ai/api/v1/chat/completions
      APIキー       : 各自のキー
      モデル        : 例) openai/gpt-4o-mini

  ・Azure OpenAI
      エンドポイント: https://{リソース名}.openai.azure.com
      APIキー       : Azureポータルの「キーとエンドポイント」から取得
      デプロイ名    : Azureでモデルをデプロイした際に自分で付けた名前
      APIバージョン : 例) 2024-06-01

  ・Gemini
      エンドポイント / APIキー / モデル / 認証方式

APIキーは画面上ではマスクされますが、appsettings.json には平文で
保存されます。取り扱いにご注意ください。

軽量で高速なモデル(gpt-4o-mini 等)を推奨します。
整形は短いテキストが対象なので、大きなモデルは待ち時間が増えるだけです。

--- 「一般」タブ ---

パレットを開くホットキー(既定 F10)を変更できます。
欄をクリックして、割り当てたいキーを押してください。

修飾キーとの組み合わせも指定できます。
  例) Ctrl+Shift+W  /  Win+Alt+X  /  F10
組み合わせたいキーを同時に押してください。

※ 指定したキーは他のアプリには渡らなくなります。
   F10 のような単独キーを割り当てると、そのキー本来の動作が
   どのアプリでも使えなくなります。日常的に使うキーを避けたい場合は、
   Ctrl+Shift+W のような組み合わせにするのが安全です。
   組み合わせにしておけば、修飾キーなしの単独入力は従来どおり通ります。

※ Windowsが予約している組み合わせ(Win+L、Ctrl+Alt+Delete など)は
   OS側が先に処理するため割り当てられません。

「整形結果を差分ハイライトで表示する」で、変更箇所の色分けを
既定でONにするか選べます(パレット上でも切り替えられます)。

「即実行」では、パレットを出さずにその場で整形して置き換える
ホットキーと、そのとき使うプリセットを設定できます。
空欄のときは無効です。「無効にする」ボタンで空欄に戻せます。
パレットと同じキーは指定できません(保存時に警告が出ます)。
確認画面が出ないため、取り消しは貼り付け先で Ctrl+Z になります。

ホットキーの変更は保存した時点で反映されます(再起動は不要)。


■ 使い方

1. 文章を入力する(Win+H の音声入力でも、手打ちでも構いません)
2. 整形したい範囲を選択する
3. F10 を押す → カーソル付近にパレットが開く
4. 整形方法をチェックする(複数選べます)
     ・整える          … フィラー除去、句読点、誤変換修正
     ・誤変換だけ直す  … 文体を変えず、同音異義語の誤りのみ修正
     ・ビジネスメール  … 丁寧な「ですます調」に整える
     ・チャット        … 口語のまま簡潔に
     ・要約            … 要点をまとめる(内容は補わない)
     ・英訳            … 英語に翻訳する
     ・和訳            … 日本語に翻訳する
   「要約」＋「英訳」のように組み合わせると、上から順に適用されます。
   ただし上の4つ(文体の指定)は互いに排他で、1つ選ぶと他が外れます。
   「文体を変えるな」と「ですます調にしろ」のように指示が矛盾するためです。
   自由指示欄に「もっと短く」などと書くと、選んだ整形のあとに適用されます。
5. 「実行」を押す(自由指示欄では Enter でも実行)
6. 結果を確認して「置き換える」→ 選択範囲が整形結果に置き換わります

整形結果は既定で差分ハイライト表示になります(赤=消えた部分、緑=入った部分)。
「差分表示」のチェックを外すと、結果をその場で手直しできます。
要約・英訳のように原文が大きく書き換わる場合は、差分が読みにくくなるため
自動的に表示されません(チェックを入れれば見られます)。

自由指示欄は過去に使った指示を覚えています。欄の右端をクリックすると
履歴から選べます(新しいものから20件)。

結果はパレット上で手直ししてから置き換えることもできます。
気に入らなければ「キャンセル」、置き換えた後なら Ctrl+Z で戻せます。


■ カスタマイズ

appsettings.json をテキストエディタで編集します。

・Polish.Presets
    パレットのチェックボックス(プリセット)を追加・編集できます。
    Instruction がそのままLLMへの指示になります。
    複数選んだときは、この並び順に上から適用されます。
    Group が同じものは同時に選べません(排他)。
      Style=文体の指定 / Length=要約 / Translate=翻訳
    Group を空にすると、どれとでも組み合わせられます。

・Formatting.AppStyleRules
    アクティブなアプリごとに文体を切り替えるルールです。
    ※現時点では整形に反映されません(将来利用するために定義だけ残しています)。
      アプリごとに文体を変えたい場合は、当面プリセットか自由指示で指定してください。

・Polish.QuickHotkey / Polish.QuickPresetName / Polish.ShowDiffByDefault
    いずれも設定画面の「一般」タブから変更できます。
    ファイルを直接編集する必要はありません。

・Glossary.txt
    用語辞書です。音声入力で誤変換されやすい表記を登録します。
    書き方は「誤変換されがちな表記 → 正しい表記」を1行に1組。
    社名・製品名・人名など、Win+H が苦手な固有名詞を入れると効果的です。
    ファイルがなくても動作します。編集後の再起動は不要です。

・PolishSystemPrompt.txt
    整形全体に共通する方針です。プリセットより優先度は低くなります。

※ 注意: アプリ起動中に appsettings.json を直接編集しないでください。
   設定画面から保存すると、その内容でファイル全体が書き換わります。
   直接編集したい場合は、アプリを終了してから行ってください。


■ 送信されるデータについて

整形のため、以下が設定したLLMのAPIへ送信されます。

  ・選択したテキスト
  ・アクティブなアプリ名
  ・カーソル周辺のテキスト(最大500文字)
  ・Glossary.txt に登録した用語辞書の全内容

周辺テキストは、固有名詞の誤変換を文脈から直す精度を上げるための
参考情報です。アプリによっては取得できず、その場合は送信されません
(取得できたかどうかはログに記録されます)。

用語辞書は毎回の整形で送信されます。組織固有の名称を登録する性質上、
登録内容もLLMプロバイダへ渡ることに留意してください。

機密情報を含むテキストを扱う場合は、利用するLLMプロバイダが
利用先の規程に適合しているか確認してください。


■ うまく動かないとき

ログを確認してください:
  %AppData%\TextPolish\logs\

よくある症状:

・「テキストが選択されていません」と出る
    → テキストを選択してからホットキーを押してください。
      それでも出る場合、対象アプリが Ctrl+C でのコピーに
      対応していない可能性があります。

・整形結果が置き換わらず、別のテキストが貼り付けられる
    → appsettings.json の TextInsertion.RestoreDelayMs を
      1500 程度に大きくしてください。
      動作の遅い環境で、貼り付け完了前にクリップボードが
      復元されてしまうことがあります。

・整形が失敗する
    → ログにHTTPステータスが出ます。
      401 はAPIキーの誤り、404 はモデル名かエンドポイントの誤りです。
